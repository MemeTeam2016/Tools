GBA Player

Runs in your browser. The ROM never leaves this computer: it's read from a file you choose and kept in this browser's storage.

Cloud saves

Cloud saves

Pick a save. When you save in the game, it uploads automatically.

    Set up cloud saves

    Saves go to the private repo . Create a fine-grained GitHub token with only that repository and Contents: Read and write, then choose a password. The token is encrypted with your password; only the encrypted copy (vault.json) is published.

    Then add the downloaded vault.json next to this page in the site's repo.

    Play without cloud saves

    Saves stay in this browser only. Use the player menu's Export / Import Save File to move them.
